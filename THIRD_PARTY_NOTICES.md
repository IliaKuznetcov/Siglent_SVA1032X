# Third-party dependencies

The application imports the following external packages. Each retains its own
licence and attribution:

| Package | Project |
| --- | --- |
| PySide6 / Qt for Python | https://www.qt.io/qt-for-python |
| NumPy | https://numpy.org/ |
| Matplotlib | https://matplotlib.org/ |
| PyVISA | https://github.com/pyvisa/pyvisa |
| scikit-rf | https://scikit-rf.org/ |

Smith-chart visualization uses scikit-rf. Instrument communication uses PyVISA;
a vendor VISA runtime, when used, is installed separately under its own terms.
